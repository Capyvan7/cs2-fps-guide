В этом гайде собраны актуальные рекомендации по настройке Counter-Strike 2 и Windows для получения максимально возможной производительности. Прирост FPS зависит от конфигурации вашего компьютера.

1. Обновите драйвер видеокарты

Перед настройкой рекомендуется установить последнюю стабильную версию драйвера.

  • NVIDIA — обновите драйвер через NVIDIA App или официальный сайт NVIDIA.
  • AMD — обновите драйвер через AMD Software: Adrenalin Edition.

После установки рекомендуется перезагрузить компьютер.

2. Включите режим высокой производительности Windows

Windows 11

  1. Откройте Параметры.
  2. Перейдите в Система → Питание и батарея.
  3. В разделе Режим питания выберите Высокая производительность или Максимальная производительность, если этот режим доступен.

Windows 10

  1. Нажмите Win + R.
  2. Введите control и нажмите Enter.
  3. Откройте раздел Электропитание.
  4. Выберите Высокая производительность.
  5. Если этот режим не отображается, нажмите Показать дополнительные схемы.

3. Настройка NVIDIA

Если у вас видеокарта NVIDIA:

  1. Нажмите правой кнопкой мыши по рабочему столу.
  2. Откройте Панель управления NVIDIA.
  3. Перейдите в Управление параметрами 3D.
  4. Откройте вкладку Программные настройки.
  5. Выберите Counter-Strike 2. Если игры нет в списке — нажмите Добавить.

Измените следующие параметры:

  • Power Management Mode → Prefer Maximum Performance
  • Texture Filtering – Quality → High Performance
  • Vertical Sync → Use the 3D application setting

Нажмите Применить.

Если у вас видеокарта AMD — этот пункт можно пропустить.

4. Подготовка Windows перед запуском игры

Перед запуском CS2 рекомендуется:

  • Закрыть браузер.
  • Закрыть OBS.
  • Закрыть ненужные программы.
  • Закрыть Wallpaper Engine (если используется).
  • Закрыть Discord Stream и другие тяжёлые приложения.
  • Оставить минимум 15–20 ГБ свободного места на диске с игрой.

Удалять папки temp, %temp% и prefetch не нужно — это практически не влияет на FPS.

5. Параметры запуска Steam

  1. Откройте Steam.
  2. Найдите Counter-Strike 2.
  3. Нажмите правой кнопкой мыши по игре.
  4. Выберите Свойства.
  5. В поле Параметры запуска введите:
-novid

Этот параметр отключает вступительный ролик и ускоряет запуск игры.

Параметры -high, -threads, -fullscreen и другие старые команды в современных версиях CS2 практически не дают прироста производительности.

6. Рекомендуемые настройки графики CS2

  • Режим экрана — На весь экран
  • Вертикальная синхронизация — Выкл
  • NVIDIA Reflex — Вкл + Boost
  • HDR — Производительность
  • Повышенный контраст игроков — Вкл
  • Тени — Низкие
  • Детализация моделей — Низкая
  • Шейдеры — Низкие
  • Частицы — Низкие

Сглаживание

  • Слабый ПК — Выкл
  • Средний ПК — CMAA2
  • Мощный ПК — 2× MSAA

FSR

Если FPS недостаточно — попробуйте включить FSR.

Если производительности хватает — лучше оставить FSR выключенным для более чёткой картинки.

7. Какое разрешение выбрать?

  • 1280×960 (4:3) — хороший вариант для слабых видеокарт.
  • 1280×1024 (5:4) — также популярное разрешение.
  • 1920×1080 — лучшее качество изображения.

Выбирайте то разрешение, с которым вам удобнее играть.

8. Если FPS всё ещё низкий

Проверьте следующее:

  • Процессор и видеокарта не перегреваются.
  • Игра установлена на SSD.
  • В системе желательно 16 ГБ оперативной памяти или больше.
  • Во время игры не запущены тяжёлые фоновые программы.

Частые вопросы

Нужно ли очищать temp и prefetch?

Нет. Это практически не влияет на FPS в CS2.

Нужно ли использовать NVIDIA Profile Inspector?

Нет. Большинству пользователей достаточно настроек через обычную Панель управления NVIDIA.

Нужно ли использовать параметр -high?

Нет. В современных версиях CS2 он практически не даёт прироста производительности и иногда может ухудшать стабильность.
